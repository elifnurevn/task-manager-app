# Task & Workflow Management Dashboard

A full-stack task management application featuring a RESTful API backend built with Python (Flask) and SQLite, alongside a responsive, dynamic JavaScript frontend.

### Features
- RESTful API endpoints handling full CRUD operations
- SQLite persistent database storage
- Dynamic DOM updates using vanilla JavaScript Fetch API
- Priority-based workflow categorization

### Built With
- Python 3
- Flask
- SQLite3
- JavaScript / HTML5 / CSS3

### Quick Start
Clone the project, install Flask, and run the server:

```bash
git clone [https://github.com/elifnurevn/task-workflow-manager.git](https://github.com/elifnurevn/task-workflow-manager.git)
cd task-workflow-manager
pip install flask
python app.py
